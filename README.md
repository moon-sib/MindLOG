# MindLog — дневник состояния с ИИ-собеседником (iPhone)

## Как устроено

1. **Знакомство** (`SetupView`) — имя, возраст (любой, необязательно), пол, цель. Показывается **один раз**.
2. **Главный экран** (`HomeView`) — последнее состояние, серия дней, график динамики, список записей. **«+» в правом верхнем углу** — новая запись, шестерёнка — настройки.
3. **Новая запись** (`NewCheckInFlow`): эмоция (`EmotionFlowView`) → опросник (`QuestionnaireView`) → чат (`ChatView`). «Завершить» сохраняет итог дня.
4. **Детали записи** (`HistoryDetailView`), удаление записи — через значок корзины или долгое нажатие в списке.
5. **Настройки** (`SettingsView`) — редактирование профиля, ежедневное напоминание, удаление всех записей.

Дизайн — Liquid Glass (iOS 26+). На iOS 17–25 вместо него используется матовое стекло.
Всё хранится локально через SwiftData.

## Как собрать (с Windows, через GitHub)

1. `git add -A && git commit -m "update" && git push`
2. GitHub → вкладка **Actions** → сборка `Build iOS` (5–10 минут).
3. `MindLog-unsigned.ipa` лежит внизу страницы запуска, в **Artifacts**.
4. Установка на iPhone с Windows: Sideloadly (или AltStore) + свой Apple ID, приложение живёт 7 дней.
5. В `project.yml` замени `com.yourname` на свой идентификатор.

`.xcodeproj` не хранится в репозитории: его создаёт XcodeGen из `project.yml`.

## Подключение настоящей нейросети

Пока `AppConfig.proxyURL = nil`, чат отвечает заглушкой (она реагирует на темы, но это не ИИ).

1. Развернуть `server.mjs` на любом хостинге с Node 18+:
   `ANTHROPIC_API_KEY=... APP_TOKEN=... node server.mjs`
2. В `ChatService.swift` указать адрес в `AppConfig.proxyURL` (и `appToken`, если задан `APP_TOKEN`).
3. Перед релизом добавить лимиты запросов на сервере (базовый лимит уже есть).

Ключ API нельзя класть в приложение: его легко достать из бинарника.
